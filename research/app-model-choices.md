# App model choices

Checked 16 November 2026. The guide covers ChatGPT Pro 500 and Claude Ultra, the renamed Max 20x plan. Picker labels, access and advertised limits come from provider documentation. An individual account's available options can depend on rollout, app version and remaining usage. [ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers), [Claude Ultra](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan)

## ChatGPT

In regular Chat, choose **GPT-6** and select **Instant**, **Medium**, **High** or **Extra High** to use GPT-6 Sol. The **Pro** setting uses GPT-6 Astra and appears as **GPT-6 Pro**. GPT-5.6 Sol remains a separately selectable family, with its own Pro option. GPT-6 Pro has a weekly allowance separate from Work and Codex. OpenAI is rolling out parallel agents for eligible GPT-6 Pro conversations. [Chat model picker](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt), [ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

In Work or Codex, choose the specific model under the composer. Use **Advanced** if the picker starts with the Power slider. The CLI uses `/model`. GPT-6.1 Sol and GPT-6.1 Terra are distinct models selected in Work or Codex. Astra, GPT-6 Sol and GPT-6 Luna also have Work and Codex options. Work and Codex share a usage allowance with no five-hour limit on Pro 500. **Ultrafast** boosts generation speed on Astra and 6.1 Sol and consumes the included allowance at eight times their Standard rate. **Ultra** in the reasoning picker uses multiple agents. Codex supports explicitly choosing each worker's model and effort, and the service tier follows the main session. [Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex), [Work and Codex limits](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex), [Model controls](https://learn.chatgpt.com/docs/models), [Subagent settings](https://learn.chatgpt.com/docs/agent-configuration/subagents)

For a small prototype, try GPT-6 High and ask for a self-contained mini app you can preview in an interactive code block. For a bug, give Chat the relevant code and a reproducible failure. [Chat model picker](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt), [Interactive code blocks](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

Start **Deep research** from the tools menu to set the sources and review the research plan. For a short lookup, choose **Search**. Use **Images** for generation or editing. The currently documented generator is ChatGPT Images 2.6. Images with thinking is available on Pro. [Deep research](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt), [Web search](https://help.openai.com/en/articles/9237897-chatgpt-search), [Images in ChatGPT](https://help.openai.com/en/articles/11084440-images-in-chatgpt)

## Claude

In Claude chat, select the model next to the send button and open **Effort**. Haiku 5.5, Sonnet 5.5, Opus 5.5 and Fable 5.2 support effort selection and keep thinking on. Claude documents Low through Max with the default labelled for each model. In Claude Code, `/model` selects the model and `/effort` changes effort. All four current models support Low, Medium, High, Extra high and Max in Claude Code and default to Medium. Older models may also appear in the picker. [Claude effort picker](https://support.claude.com/en/articles/8664678-change-the-model-effort-and-thinking-settings), [Claude Code model configuration](https://code.claude.com/docs/en/model-config)

Claude chat and Claude Code share the weekly allowance. Fable can use up to half of that same weekly allowance, with a separately tracked cap. Verified Ultra accounts have no five-hour limit. Other Ultra accounts can have a temporary five-hour limit. Claude Code's built-in Explore worker follows the parent model in most cases. A Fable parent on a subscription uses Opus for the built-in Explore worker. A custom Explore worker can specify Haiku for read-only code search. [Ultra limits](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan), [Fable access and limits](https://support.claude.com/en/articles/15424964-claude-fable-models-on-your-plan), [Claude Code limits](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan), [Claude Code subagents](https://code.claude.com/docs/en/sub-agents)

Enable web search and choose **Research** from the **+** menu for a multi-search investigation across the web and enabled connectors. Ask for an artifact to preview a small prototype directly in chat. Use **Design** when editable layout matters. Claude chat can produce HTML and SVG visuals. For generated raster artwork or photo edits, use ChatGPT Images. [Claude Research](https://support.claude.com/en/articles/11088861-use-research-on-claude), [Claude Design](https://support.claude.com/en/articles/14604416-get-started-with-claude-design), [Claude Artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them), [Claude image capabilities](https://support.claude.com/en/articles/9002504-can-claude-produce-images)

## Recommendations and evidence

The starting choices in [app-model-choices.json](app-model-choices.json) are editorial recommendations for the named task. Provider documentation establishes availability and recommended uses. Linked evaluations and experiments supply workload-specific observations. The app selections were checked against published documentation and have no measured account-specific response times.

- **Quick answers.** Instant in Chat and Haiku 5.5 Low in Claude are provider-documented starting points for short work.
- **Writing.** Arena's writing preferences support trying Opus 5.5 High when tone matters. The rating comes from creative writing prompts. Short drafting from supplied material also fits OpenAI's positioning for GPT-6.1 Terra. [Arena Creative Writing](https://arena.ai/leaderboard/chat/text/creative-writing), [Work and Codex model guidance](https://learn.chatgpt.com/docs/models)
- **Research.** The recommended tools are based on source controls and connector access. The current snapshot has no matched comparison of the two product tools. [ChatGPT Deep research](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt), [Claude Research](https://support.claude.com/en/articles/11088861-use-research-on-claude)
- **Web apps.** DesignArena mixes several kinds of agent-produced work and rated Opus 5.5 High highest in the collected rows. Plato's results favour Fable 5.2 Low for replicating known apps under a test that used different harnesses and budgets. Its 62% average took about six hours per run. [DesignArena](https://www.designarena.ai/leaderboard), [Plato Web Clone Bench](https://plato.so/research/web-clone-bench/)
- **Bug fixes.** Codex Sol as a first pass follows OpenAI's model guidance and the availability of repo editing and test execution. The linked Claude bug studies concern bounded public-library faults and do not test this Codex configuration. [Work and Codex model guidance](https://learn.chatgpt.com/docs/models), [Report provenance](reports.md)
- **Hard reasoning.** Fable 5.2 configurations hold the top results on the interactive ARC-AGI-3 game set. Its Extra high entry used an earlier checkpoint and its Max entry hit the evaluation timeout on 28 of 55 games. The app recommendation starts at High. Astra's 62.7% entry uses Max in the benchmark harness. Chat's Pro setting has no verified one-to-one mapping to that benchmark configuration. [ARC-AGI-3 Fable 5.2](https://arcprize.org/results/anthropic-claude-fable-5-2), [Benchmark provenance](benchmarks.md)
- **Posters and images.** ChatGPT Images 2.6 and Claude Design serve distinct deliverables. Earlier ChatGPT Images results are version-specific and do not describe 2.6. [Images in ChatGPT](https://help.openai.com/en/articles/11084440-images-in-chatgpt), [Claude Design](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)
- **Parallel work.** Use separate agents for independent tasks and give the parent agent responsibility for integration. The Claude Explore experiment tested read-only searches. Google studied the effect of coordination architecture across models and observed task-dependent results. [Report provenance](reports.md)
